
## RecipeWise v2.1 — Session May 28, 2026 (Morning)

### Major Bug Fixes
- **Profile crash**: `useThemeContext()` was imported in `profile.tsx` but `ThemeProvider` was never mounted in the app. Removed the import/call — dark mode now follows system setting (read-only).
- **Extra tabs in tab bar**: Files like `add-link.tsx`, `my-links.tsx`, `premium.tsx`, `onboarding.tsx`, `[id].tsx` are siblings of `_layout.tsx` — Expo Router auto-creates tabs for ALL files in the same directory. Fixed by adding `href: null` to hide them from tab bar.
- **`detectSource` not exported**: `add-link.tsx` imported `detectSource` from `my-links.tsx`, but it was defined as `function` (not `export function`). Added `export` keyword.
- **My Recipe Links not discoverable**: After saving a YouTube link, it went to a separate "My Recipe Links" screen — user expected it in "Saved Recipes" on Profile. Added a **My Recipe Links (N)** card to Profile tab for easy navigation. Also changed "Done" button to navigate to `/my-links` instead of just `router.back()`.
