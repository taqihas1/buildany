### Hermes Orchestration — DECISIONS LOCKED IN (June 9, 2026)

**UI for status updates:** AI chat panel (real-time progress messages)
**Decision points:** ONLY on failures (auto-flow on success, pause when something breaks)
**Training data:** Learns from project outcomes (success/failure patterns)

**The Flow:**
```
User Prompt → Hermes starts
  ↓ [AI chat: "⚡ Starting code generation..."]
Code Agent → generates files
  ↓ [AI chat: "✅ Code generated (12 files)"]
Test Agent → runs tests
  ↓ [AI chat: "🧪 Running tests..." → "✅ All tests passed" OR "⚠️ 3 tests failed"]
  ↓ (on failure) → PAUSE → "Tests failed. Auto-fix or review?"
Code Review Agent → reviews code
  ↓ [AI chat: "🔍 Code review complete — 2 suggestions"]
Preview Agent → builds preview
  ↓ [AI chat: "🚀 Preview ready!"]
User Approval Gate → "Deploy?" / "Make changes?"
```

**Learning Rules (Hermes will accumulate):**
- If test fails → next time, run stricter pre-flight before test
- If preview breaks after code gen → always validate syntax before preview
- If user rejects output → log rejection reason, adjust next prompt
- Success streak on mobile projects → auto-approve similar projects
- High failure rate with web HTML → add extra validation step
