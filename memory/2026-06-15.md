## BuildAny ↔ Hermes Bridge
- API route: `/root/buildany/src/app/api/hermes-chat/route.ts`
- React hook: `/root/buildany/src/hooks/useHermesChat.ts`
- Endpoint: `POST /api/hermes-chat` — public route (added to `PUBLIC_API_ROUTES` in middleware)
- Bridge flow: Next.js API → `docker exec hermes chat -f <tmpfile> -Q` → parse stdout → return JSON
- **Critical:** Temp files MUST be written to the mounted data directory (`/docker/hermes-agent-cvaj/data/`) so the container can read them. Writing to `/tmp/` on host fails because container can't access host `/tmp/`.
- Response parser extracts text between `⚕ Hermes` header and `Session:` footer.
- Confirmed working via curl to `https://base66.cloud/api/hermes-chat`
