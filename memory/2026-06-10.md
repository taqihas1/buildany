### DB Schema Mismatch

The `/docker/buildany/sqlite.db` has OLD schema missing `project_id` column:

```sql
CREATE TABLE "agents" (
  `id` text PRIMARY KEY NOT NULL,
  `name` text NOT NULL,
  `type` text NOT NULL,
  `status` text DEFAULT 'idle',
  `capabilities` text,
  `last_heartbeat` integer,
  `metadata` text,
  `created_at` integer
  -- NO project_id column!
);
```

While `/root/buildany/` had newer schema with `project_id` (from `git pull` and `drizzle-kit generate`).

### Fix Applied

1. **Pulled latest code in CORRECT directory:**
   ```bash
   cd /docker/buildany && git pull origin main && npm run build && pm2 restart buildany --update-env
   ```

2. **Added missing `project_id` column to agents table:**
   ```bash
   sqlite3 sqlite.db "ALTER TABLE agents ADD COLUMN project_id TEXT;"
   ```

3. **Rebuilt and restarted PM2 with correct exec path**
