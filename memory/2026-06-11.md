# BuildAny 502 Fix - 2026-06-11

## Root Cause
The Next.js app (buildany) was NOT actually running on port 3000. PM2 showed "online" but there was no actual Node process or port listener. The app was configured to run from `/docker/buildany` (wrong directory) instead of `/root/buildany` (where the actual source code is).

## Symptoms
- Traefik returning 502 for https://base66.cloud
- `curl http://localhost:3000` returned 000 (connection refused)
- PM2 showed "online" but no PID file, no port 3000 listener
- `ss -tlnp` showed no process on port 3000

## Fix Applied
1. Deleted the ghost PM2 process: `pm2 delete buildany`
2. Started new process from correct directory: `cd /root/buildany && pm2 start npm --name buildany -- start`
3. Verified app is listening on port 3000
4. Saved PM2 config: `pm2 save`

## Result
- https://base66.cloud now returns 200
- Let's Encrypt certificate valid (expires Sep 3, 2026)
- Both HTTP and HTTPS working correctly

## Remaining Items
- Traefik config uses `tls: {}` instead of `certResolver: letsencrypt` - certificate is cached in Docker volume. Should update to use proper certResolver for auto-renewal.
- The PM2 JSON parse error in logs (`List tasks error: SyntaxError: Unexpected token '<'`) is a separate app-level issue, not infrastructure-related.

`src/app/api/generate/route.ts` had a `TS18048` error: `'project' is possibly 'undefined'`.

2. **Route-level auth checks**: Even after middleware fix, the route handlers (`tasks/route.ts`, `agents/route.ts`, `decompose/route.ts`) had `if (!userId) return 401` blocking guest users
3. **TypeScript build error**: `generate/route.ts` had `Type error: 'project' is possibly 'undefined'` at line 101 — blocking production build
4. **Old project orphaned**: Project `cab78cbb-c369-4942-830b-df02fd8779b3` was created before fixes, has 0 tasks and 0 agents in DB

### Fixes Applied

#### A. Middleware Fix (src/middleware.ts)
Added `/api/project` (no trailing slash) to `PUBLIC_API_ROUTES`:
```typescript
const PUBLIC_API_ROUTES = [
  '/api/generate',
  '/api/orchestrate',
  '/api/decompose',
  '/api/deploy',
  '/api/project',      // ← ADDED (matches /api/project/123/tasks, /api/project/123/agents)

```

#### B. Route Auth Removal
Removed `if (!userId) return 401` from:
- `/root/buildany/src/app/api/project/[id]/tasks/route.ts` (GET and POST)
- `/root/buildany/src/app/api/project/[id]/agents/route.ts` (GET)
- `/root/buildany/src/app/api/decompose/route.ts` (POST and GET)

All now allow guest access with `// Allow guest access` comment.

#### C. TypeScript Fix (src/app/api/generate/route.ts)
Changed `let project: any;` to `const` declarations with early returns. TypeScript couldn't narrow type after `if/else` reassignment. Now each branch returns immediately, no top-level `let`.
