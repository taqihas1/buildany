## Key Bugs Fixed

### 1. Expo Entry Point Crash
- **Cause**: `"main": "expo/AppEntry.js"` in package.json
- **Fix**: Changed to `"main": "node_modules/expo/AppEntry.js"`
- `expo/AppEntry.js` only exists when `expo-router` is installed, which this project doesn't use

### 2. Google Mobile Ads Plugin Crash
- **Cause**: `react-native-google-mobile-ads` is a **native module** that Expo Go doesn't include
- **Fix**: Temporarily removed from app.json plugins array
- **Note**: For production builds, need `expo-dev-client` + custom development build, not Expo Go

### 3. Missing PaperProvider
- **Cause**: `react-native-paper` v5 requires `<PaperProvider>` wrapper in App root
- **Fix**: Added PaperProvider import and wrapper around AppNavigator in App.tsx

### 4. Empty Sparkle Component in SplashScreen
- **Cause**: Sparkle child component had empty return `return ( );`
- **Fix**: Simplified SplashScreen.tsx with clean fade animation, removed broken sparkle

### 5. Node.js Version Mismatch
- **Current**: v20.11.0
- **Required by dependencies**: >= 20.19.4
- **Status**: Warnings persist but app still runs. Should upgrade with `brew upgrade node` eventually

### 6. npm Cache Permission Error
- **Fix**: `sudo chown -R 501:20 "/Users/taqihasan/.npm"`
