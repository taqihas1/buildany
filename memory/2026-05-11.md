### Major Technical Insight

The user asked: *"Can I upload a template and have OpenClaw build the skill?"*

Answer: **Yes, with `skill_from_template.py`.**

This script:
1. Parses any Markdown template for `{{placeholders}}`
2. Builds JSON schema matching template structure
3. Auto-generates `generator.py`, `SKILL.md`, `sample-intake.json`
4. Packages into `.skill` file

**This means users can design templates in Word/Google Docs, convert to Markdown with placeholders, and get a complete working skill without writing code.**

### User's Intent

- Upload a template

We built `all-in-one-installer.sh` as the closest approximation: a single file that contains all code, templates, and scripts, which when run:

[2026-05-11 11:22] — BentoPDF Client-Side Deployment Research
  - BentoPDF is 100% client-side (browser-based, no server processing needed).
  - All PDF operations happen in browser memory; files never leave the device.
  - Works offline once page is loaded (cached WASM modules).
  - Multiple local deployment options for user laptops:
    1. Docker (single command): `docker run -p 3000:8080 ghcr.io/alam00000/bentopdf:latest`
    2. Static files: Download `dist-{version}.zip` from GitHub releases, extract, open index.html
    3. Build from source: `git clone`, `npm install`, `npm run build`, `npm run preview`
    4. Air-gapped bundle: Use `prepare-airgap.sh` to bundle WASM modules for fully offline use
  - Key insight: For proposal/RFP workflow, BentoPDF can run locally on each user's laptop without any server infrastructure.
  - WASM modules (for advanced features like Office conversion, OCR) load from CDN by default but can be self-hosted.
  - Cross-origin isolation required for SharedArrayBuffer (LibreOffice WASM) — `http://localhost` works, LAN IPs need HTTPS.
  - User's context: Looking for simplest way to let team members edit PDFs locally without uploading to external servers.

  - Added `md_to_docx.py` script to the `rfp-document-converter` skill.
  - Converts Markdown → Word .docx using python-docx.
  - Preserves headings, tables, bullet lists, and bold formatting.
  - Title headings are styled with blue (#3182ce) for visual hierarchy.
