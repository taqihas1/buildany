# App Ideas — Future Projects

## HotSell — Amazon/Walmart Trending + Alibaba Sourcing
**Status:** Not started. Idea only.
**Priority:** Low (TradePulse is current focus)

### Concept
App that lists hottest-selling items on Amazon and Walmart, then matches them with suppliers from Alibaba.com. Users see what's trending AND where to source it profitably.

### Features
1. **Trending Items** — Scrape or API-pull top-selling items from Amazon (Best Sellers, Movers & Shakers) and Walmart
2. **Alibaba Matching** — For each hot item, find similar products from trusted Alibaba suppliers
3. **Supplier Filter** — Only show suppliers who:
   - Ship to US
   - Have Gold/Verified badges
   - Minimum order quantities (MOQ)
4. **Profit Calculator** — Estimated margin: Amazon selling price vs Alibaba unit cost + shipping
5. **Category Filters** — Electronics, home, fashion, beauty, etc.

### Tech Stack
- React Native + Expo (same as other apps)
- Scraping or affiliate APIs for Amazon/Walmart data
- Alibaba API or web scraping for supplier data
- Firebase or local storage for saved items

### Name Ideas
- HotSell, SourceSpot, TrendSourcer, AliMatch
