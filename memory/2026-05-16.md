## Lessons Learned
- EAS builds can succeed even with minor react/react-native version mismatches if the major versions align with SDK
- `.easignore` is critical for large workspaces — archive was 289MB before exclusion, much smaller after
- Duplicate `@expo/vector-icons` (explicit dep + bundled with SDK) causes Gradle failures in EAS
- `npx expo install --check` is the reliable way to align dependencies with SDK version
- Build logs accessible via `eas build:view <id> --json | jq '.logFiles'` even without dashboard access
- `eas init` (non-interactive with `yes | eas init`) successfully creates + links EAS project
