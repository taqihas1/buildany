**What it does**:
- AI-powered code review CLI tool from Alibaba Group (Alibaba Group, tens of thousands of developers, millions of code defects identified)
- Hybrid architecture: deterministic pipelines + LLM Agent
- Reads Git diffs, sends changed files to LLM via agent with tool-use capabilities
- Generates structured review comments with line-level precision
- Built-in fine-tuned ruleset (NPE, thread-safety, XSS, SQL injection)
- Compatible with OpenAI & Anthropic
- Can be integrated into CI/CD pipelines

**Why useful for BuildAny**:
- BuildAny generates code that may have bugs — this tool can review it automatically
- Catches security issues (XSS, SQL injection), null pointer exceptions, thread-safety issues
- Can be integrated as a "Code Review Agent" in the swarm
- Runs deterministic checks + LLM reasoning — perfect for generated code quality
- Can suggest fixes that the orchestrator can apply before showing code to user
