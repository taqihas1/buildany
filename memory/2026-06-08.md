## Critical Lesson: NEVER Use Heredocs for VPS File Writing
- The `cat > file << 'EOF'` pattern is **unreliable** when the content contains nested quotes, backticks, or other heredoc terminators
- The `cat > /tmp/fix-all.sh << 'SCRIPT'` approach failed because the nested `<< 'EOF'` inside the script closed the outer heredoc early
- This resulted in garbled/corrupted file content on the VPS
- **Use `base64` encoding instead**: encode the file content locally, then pipe through `base64 -d` on the VPS - this is the only reliable way to write complex files via chat
