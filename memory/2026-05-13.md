# Lessons Learned: Expo React Native Project Setup

## Date: 2026-05-13
## Project: Dealership App (React Native + Expo)

### Issues Encountered and Fixes Applied

#### 1. Expo SDK Version Mismatch
- **Problem:** User's Expo Go app was on SDK 54, but project was created on SDK 51
- **Symptom:** "This project uses SDK 51 but your Expo Go app only supports SDK 54"
- **Fix:** Upgraded project to SDK 54:
  ```bash
  npm install expo@~54.0.0 react-native@0.81.1 react@19.0.0 --save --legacy-peer-deps
  ```
- **Lesson:** ALWAYS check user's Expo Go version BEFORE creating project. iOS users cannot downgrade Expo Go.

#### 2. npm ERESOLVE Peer Dependency Conflict
- **Problem:** `npx expo install @react-navigation/...` failed with ERESOLVE
- **Root cause:** npm v7+ strict peer dependency checking
- **Fix:** Use `--legacy-peer-deps` flag on ALL npm installs in Expo projects
- **Lesson:** Expo's dependency tree has peer dep conflicts by design. Never use npm without `--legacy-peer-deps`.

#### 3. React Version Mismatch (Critical!)
- **Problem:** `Error: Incompatible React versions: react@19.0.0 vs react-native-renderer@19.1.0`
- **Root cause:** react-native-renderer (what Metro actually bundles) must match react exactly
- **Fix:** Check what react-native-renderer wants, then install that exact version:
  ```bash
  npm install react@19.1.0 --save --legacy-peer-deps
  ```
- **Lesson:** `react` and `react-native-renderer` must be IDENTICAL, not just semver-compatible. Always verify after SDK upgrade.

#### 4. ngrok Tunnel Connectivity Issues
- **Problem:** "Could not connect to development server" even though server was running
- **Root cause:** ngrok tunnel expired or returned HTTP errors
- **Fix:** Kill all expo processes, clear `.expo/` folder, restart:
  ```bash
  pkill -f "expo start"
  rm -rf .expo/
  npx expo start --tunnel --clear
  ```
- **Lesson:** ngrok tunnels can go stale. Always verify tunnel health with `curl` before telling user to scan QR.

#### 5. Metro Bundler Cache Corruption
- **Problem:** "unexpected end of JSON input" errors
- **Root cause:** Metro cache had stale compiled bundles from previous SDK version
- **Fix:** Start with `--clear` flag to wipe Metro cache
- **Lesson:** ALWAYS use `--clear` after any SDK version change.

#### 6. Multiple Expo Server Instances on Port 8081
- **Problem:** "Port 8081 is running this app in another window"
- **Root cause:** Old expo process still running from previous attempt
- **Fix:** `pkill -f "expo start"` before starting new server
- **Lesson:** Check for existing processes before starting expo. Old sessions can linger.

### What We Fixed (New Issues Discovered)

#### 7. Navigation Package Version Mismatch
- **Problem:** `TypeError: undefined is not an object` — React runtime crash
- **Root cause:** `@react-navigation/native-stack@^7.15.0` incompatible with `@react-navigation/native@^6.1.18`
- **Fix:** Downgraded native-stack to v6: `npm install @react-navigation/native-stack@^6.11.0 --legacy-peer-deps`
- **Lesson:** ALL @react-navigation/* packages must share the same major version!

#### 8. QR Code Opens Safari Instead of Expo Go
- **Problem:** QR code with `https://` opens Safari showing JSON manifest
- **Root cause:** iOS handles `https://` URLs in Safari by default
- **Fix:** Use `exp://` protocol in QR codes: `exp://u7awrsy-anonymous-8081.exp.direct`
- **Lesson:** Always generate QR with `exp://` prefix for iOS Expo Go

#### 9. Expo Go Caches Old App Version
- **Problem:** "Downloaded bundle but got error" — old cached app loads
- **Root cause:** Expo Go "Recently Opened" section caches app entries
- **Fix:** Swipe left on old app entry → Delete, then scan fresh QR
- **Lesson:** Always delete old cached entries before loading updated builds

#### 10. Manual URL Entry Workflow
- **Problem:** QR scanning fails or opens wrong app
- **Workaround:** 
  1. Open Safari → go to tunnel URL → shows JSON manifest
  2. Copy URL from address bar
  3. Open Expo Go → tap "Enter URL manually" → paste URL
  4. App loads correctly
