
# RFP Scoring Rubric Template

## Scoring Scale

| Score | Description |
|---|---|
| **5 — Excellent** | Exceeds requirements significantly. Demonstrates deep understanding, innovative approach, strong evidence. Would be considered best-in-class. |
| **4 — Good** | Meets all requirements with some added value. Demonstrates solid understanding and competence. Minor areas for improvement. |
| **3 — Satisfactory** | Meets core requirements adequately. Standard approach with no significant issues or standout strengths. |
| **2 — Below Average** | Partially meets requirements. Some concerns about approach, capability, or completeness. Would require significant clarification or mitigation. |
| **1 — Poor** | Fails to meet basic requirements. Major concerns about capability, understanding, or approach. Significant risk if selected. |
| **0 — Non-Compliant** | Did not address requirement OR failed mandatory requirement. Automatic disqualification if mandatory. |

## Category 3: Pricing & Commercial Terms (Weight: 25%)

| Sub-Criteria | Weight | Score (0-5) | Weighted Score | Notes |
|---|---|---|---|---|
| **3.1 Total Cost of Ownership (TCO)** | 25% | | | Is the overall price competitive and reasonable for scope? |
| **3.2 Pricing Transparency** | 20% | | | Is pricing clearly broken down? Are rate cards provided? Can we understand what drives cost? |
| **3.3 Value for Money** | 20% | | | Does the proposal offer good value relative to price? Are there cost efficiencies or optimizations proposed? |
| **3.4 Commercial Flexibility** | 15% | | | Are they flexible on payment terms, milestones, change order handling? |
| **3.5 Risk Sharing** | 10% | | | Do they share risk through fixed-price components, performance guarantees, or penalties? |
| **3.6 Hidden Costs / Surprises** | 10% | | | Are assumptions clear? Are there obvious gaps or likely change orders? |
| **Category 3 Subtotal** | **100%** | | **/5** | |
| **Category 3 Weighted Score** | | | **/5 x 25% =** | |

**Scoring Guidance for Category 3:**
- **5:** Competitive pricing, excellent transparency, clear value proposition, flexible terms, strong risk-sharing mechanisms
- **4:** Reasonable pricing, good transparency, solid value, acceptable terms
- **3:** Market-rate pricing, adequate breakdown, fair value, standard terms
- **2:** High pricing OR poor transparency, unclear value, rigid terms, significant hidden cost risk
- **1:** Uncompetitive pricing, opaque pricing, poor value, unacceptable terms

**IMPORTANT — Price Scoring Method (choose one):**

**Option A: Relative Price Scoring (Recommended for competitive RFPs)**
```
Price Score = (Lowest Bid / Vendor Bid) x Maximum Price Points
```
Example: If lowest bid is $500K and maximum price points = 25:
- Vendor A: $500K → (500/500) x 25 = 25 points
- Vendor B: $600K → (500/600) x 25 = 20.8 points
- Vendor C: $750K → (500/750) x 25 = 16.7 points

**Option B: Absolute Price Scoring (If you have a budget ceiling)**
```
- Within budget: Full points
- 0-10% over budget: 80% of points
- 10-20% over budget: 60% of points
- >20% over budget: 0 points (disqualify or require justification)
```
