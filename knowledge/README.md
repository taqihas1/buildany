# Open Knowledge Format (OKF) - My Workspace

This is my personal knowledge base for working with the user.
It contains everything I need to remember about the user, projects, and our shared history.

## Structure

```
knowledge/          # Curated knowledge about the user and projects
├── user-profile.md   # Who the user is, how they work, what they like
├── project-buildany.md # BuildAny project history and decisions
├── project-tradepulse.md # TradePulse app history
├── project-recipewise.md # RecipeWise app history
└── decision-log.md   # Key decisions we've made together

skills/             # My capabilities and skill definitions
├── okf-usage.md      # How to use this OKF structure
└── communication.md  # How to communicate with the user

state/              # My runtime state
└── session-history.md # Summary of recent sessions
```

## Usage Rules

1. **Check knowledge before assuming** — Don't guess about user preferences
2. **Update after learning** — When the user teaches me something new, write it
3. **Link related knowledge** — Connect topics with markdown links
4. **Update timestamps** — Keep frontmatter current
